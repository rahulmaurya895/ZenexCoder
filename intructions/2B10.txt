SECTION 2: DICTATION (VOICE INPUT)
================================================================================

Goal: Let the user click a mic icon in the ChatInput bar and speak their prompt.

2.1 useDictation.js (src/hooks/)
  - Utilize `window.SpeechRecognition` or `window.webkitSpeechRecognition`.
  - Export state: `isListening`, `transcript`, `error`.
  - Export functions: `startListening()`, `stopListening()`.
  - Handle continuous transcription so the user can pause and continue speaking 
    before sending the message.

2.2 DictationMic.jsx
  - Placed inside `ChatInput.jsx` (Phase 1) next to the Attach File button.
  - Default state: Muted Mic icon (Text Secondary).
  - Listening state: Primary color (#7C3AED) with a CSS radial pulse animation.
  - When listening stops, automatically append the `transcript` to the existing 
    text in the `ChatInput` textarea.

SECTION 3: NOTIFICATION CENTER
================================================================================

Goal: In Parts 2-9, we relied on a generic 'notify:show' IPC event. Now we 
capture those, show a temporary toast, and keep a persistent history so the user 
doesn't miss background agent actions.

3.1 notificationStore.js
  {
    notifications: Notification[], // { id, title, message, type, timestamp, read }
    unreadCount: number,
    addNotification(payload),
    markAllAsRead(),
    clearAll()
  }

3.2 IPC Listener (App.jsx or Layout Root)
  - Listen for `notify:show` from the main process.
  - Dispatch to `notificationStore.addNotification()`.

3.3 NotificationToast.jsx
  - Rendered via a React Portal at the top-right of the screen.
  - Automatically dismisses after 5 seconds.
  - Color coded by type:
    - Success (Green): Git push successful, Environment created.
    - Warning (Amber): Agent needs approval, Network retry.
    - Error (Red): MCP Connection failed, Git merge conflict.
    - Info (Blue): File saved, Hook triggered.

3.4 NotificationCenter.jsx
  - Accessible via a Bell icon in the TopBar (with a small red badge for `unreadCount`).
  - Slide-over panel (right side, similar to Progress Tracker).
  - Lists notifications chronologically.
  - "Clear All" button at the top.
