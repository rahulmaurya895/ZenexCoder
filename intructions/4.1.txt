SECTION 0: CONCEPTUAL INTRODUCTION FOR BEGINNERS
================================================================================

WHAT IS A SELF-LEARNING ENGINE?
Usually, an AI is "stateless"—it makes a mistake, gets corrected, but forgets 
that correction by the time you start a new chat.

The "Self-Learning Engine" changes this. When an AI agent fails (e.g., runs a 
command that errors out) and you (the human) correct it, or it auto-heals, 
the system creates a "Retrospective Log". 
- It maps the Error -> The Failed Attempt -> The Successful Fix.
- It saves this as a "Learning Rule".
- Next time, BEFORE the Swarm Architect starts, it searches this table. If it 
  sees a match, it injects: "Warning: In this scenario, don't use X, use Y."

SECTION 2: THE FAILURE PATTERN ANALYZER
================================================================================

Goal: Detect repeating failures and generalize them into rules.

2.1 retrospectiveHandler.js (electron/handlers/)
  - Periodically (or after every agent run) scan `approvals_log` (rejections) 
    and `change_records` (reverted changes).
  - Use a clustering algorithm (or simple string similarity on error messages) 
    to see if the SAME error type happened >3 times.
  - If a pattern is detected, trigger the `patternAnalyzer.js`.

2.2 patternAnalyzer.js (src/utils/)
  - Input: List of Failed Agent Runs + Error Logs.
  - Logic: 
    1. Extract the "Action Type" (e.g., `terminal_run`).
    2. Extract the "Error Message".
    3. Generate a "Lesson": "For terminal command X, always include flag Y to 
       avoid error Z."
  - Output: A new rule object: `{ trigger: string, avoid: string, suggest: string }`.

SECTION 3: ADAPTIVE SYSTEM PROMPTS (SWARM INTEGRATION)
================================================================================

Goal: Inject the AI's own "experience" into the Swarm context.

3.1 swarmHandler.js (Phase 3 EXTENSION)

  - Inject into Architect Prompt:
    ```text

    - Rule: {rule.trigger} -> Avoid {rule.avoid}, use {rule.suggest}.
    ```
