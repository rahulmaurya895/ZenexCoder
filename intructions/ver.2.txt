[UPDATED: 2026-08-10] — MODULE 7: MULTI-MODAL UI GENERATOR (VISION-TO-CODE)
- Swarm Vision Persona (`swarmPersonas.js`): Added `vision_engineer` persona to analyze UI screenshots, wireframes, or sketches and output React + Tailwind CSS components.
- Image Drag-and-Drop Handler (`ImageDropzone.jsx`): Built drag-and-drop zone wrapping `ChatPanel.jsx` to capture paste and drop events for UI mockups.
- Native Image Payload Compression (`visionHandler.js`): Resizes base64 images to 1280px max dimension JPEG (< 500KB) using Electron `nativeImage` to prevent API/IPC payload bottlenecking.
- Live Component Preview Panel (`VisualPreviewPanel.jsx`): Built isolated iframe live rendering sandbox alongside Monaco Editor with Visual / Code tabs and workspace save buttons.

[UPDATED: 2026-08-10] — MODULE 6: META-PROMPT OPTIMIZER ENGINE (XML CoT EXPANSION)
- High-Speed Preprocessing (`promptEngineHandler.js`): Intercepts raw user prompts and expands them in < 5ms into structured XML tags (`<objective>`, `<context>`, `<constraints>`, `<reasoning_protocol>`, `<output_format>`).
- Auto-Prompt UI Toggle (`PromptOptimizerToggle.jsx`): Built toggle button with Sparkles icon in `ChatInput.jsx` to switch between Auto-Prompt XML Mode and Raw Prompt mode.
- Context-Aware System Ingestion: Automatically injects current project framework (`React/Vite/Electron`) and workspace path into prompt `<context>`.
- Collapsible XML Inspector (`MessageBubble.jsx`): Added a "View Structured XML Meta-Prompt (<800ms CoT Expansion)" collapsible dropdown for users to view how raw prompts were expanded for Swarm Architect.

[UPDATED: 2026-08-10] — MODULE 5: PROACTIVE CHAOS ENGINEERING AGENT (RED-TEAM SANDBOX)
- Swarm Red-Team Persona: Added `chaos_agent` persona to `swarmPersonas.js` with malicious red-team system prompt for stress testing edge cases.
- Isolated Sandbox Execution (`chaosHandler.js`): Automatically listens for file save events, generates destructive vectors (null parameters, high memory stress arrays, SQL injection payloads), and executes them strictly inside the Windows Sandbox (`sandboxRunCommand`).
- Crash Capture & Preemptive Patching: If a test script crashes the Sandbox, captures the stack trace and generates a preemptive code patch.
- Red-Themed UI (`ChaosMonitor.jsx`): Built dedicated visual dashboard in Settings with dark red borders (`.chaos-red-theme`), live attack simulation stream, crash filter chips, and interactive patch suggestion cards.

[UPDATED: 2026-08-10] — MODULE 4: HYPER-PERSONALIZED SHADOW AI (STYLE-AWARE AUTOCOMPLETE)
- Created `shadowAIHandler.js` in Electron main process to fetch GitHub commit patches and parse AST style heuristics (indentation spaces/tabs, string quotes ' vs ", naming camelCase/snake_case).
- Encrypted Profile Storage: Style heuristics stored in `nexcode-shadow-style-profile.json` using `safeStorage` without raw code plain-text retention.
- Style Profile Injection: Updated `speculativeHandler.js` (`startSwarmRun()`) to prepend `buildStylePromptPrefix()` to autocomplete prompts, forcing inline completions to strictly mirror user formatting conventions.
- Created `ShadowTrainerUI.jsx` in Settings / Integrations Hub for selecting baseline GitHub repositories and authorizing access via GitHub PAT.

[UPDATED: 2026-08-10] — MODULE 3: ULTRA-FAST SEARCH INGESTION (SerpApi INTEGRATION)
- Created UI component `SerpApiSettings.jsx` in SettingsPanel to store and encrypt SerpApi keys via `safeStorage`.
- Built `fastSearchHandler.js` with `executeFastSearch(query)` calling the SerpApi Google engine endpoint.
- High-Speed Parsing (< 1.5s): Extracts `organic_results` (top 5), `answer_box`, and `related_questions` and minifies them into clean Markdown string to prevent context-window overflow.
- Persona Tooling & Directives: Added `web_search_fast` to `allowedTools` in `swarmPersonas.js` for Senior Dev (Coder) and SecOps. Updated system prompts to strictly prioritize `web_search_fast` over heavy Playwright browser navigation when querying syntax, API docs, or error solutions.
- System Context Routing: Updated `toolSystemContext()` in `aiHandler.js` to enforce fast API search dispatches.
